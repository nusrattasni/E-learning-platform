# 🎓 E-Learning Platform (Learning Management System)

A modern **Learning Management System (LMS)** built using **Laravel**, **React**, **Inertia.js**, and **MySQL**. This platform enables students to access courses, monitor their learning progress, and earn certificates, while administrators can efficiently manage courses, users, and educational content.

---

## 📌 Project Overview

This project was developed as part of my Software Development Internship at **Mystrix IT**. The goal was to create an interactive online learning platform similar to DataCamp or Udemy, where students can learn through structured courses and track their progress.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/nusrattasni/E-learning-platform.git
```

### Go to project directory

```bash
cd E-learning-platform
```

### Install PHP dependencies

```bash
composer install
```

### Install JavaScript dependencies

```bash
npm install
```

### Copy environment file

```bash
cp .env.example .env
```

### Generate application key

```bash
php artisan key:generate
```

### Configure database

Update your `.env` file with your MySQL database credentials.

### Run database migrations

```bash
php artisan migrate
```

### Start Laravel server

```bash
php artisan serve
```

### Start Vite

```bash
npm run dev
```
